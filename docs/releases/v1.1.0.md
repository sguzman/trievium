# Trievium v1.1.0 — Visual and ordering improvements

Explicitly requested by the owner after the v1.0.0 MVP acceptance.

- Color emoji support through native egui 0.37 system-font fallback. Install a color emoji font on Linux (e.g. `noto-fonts-emoji` on Arch); the application does not bundle fonts.
- Automatic stable OKLCH-derived accent swatches shown **before** each shortcut.
- Editable accent color in the manager, with Auto reset.
- Move Up/Down controls in the manager, with saved picker display order independent of assigned shortcut keys.
- Startup-latency improvement: defer system emoji and optional font loading until after the first paint opportunity; avoid rewriting unchanged mnemonic caches on every opening.

Compatibility: Existing schema-v1 items remain readable; `color` is optional and is saved only for an override. Reordering preserves entry labels, text, and mnemonic/pinned shortcut behavior. Clipboard, one-shot picker, and Wayland/Hyprland handling are unchanged.

The Linux x86-64 release archive and SHA-256 checksum come from the CI-gated release workflow.
