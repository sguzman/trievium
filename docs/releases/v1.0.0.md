# Trievium v1.0.0 — Stable MVP

Trievium's first stable release. The accepted feature set is frozen and the project enters maintenance.

### Included

- Native Rust/egui Linux prefix picker, immediate shortest-unique-prefix selection, prefix-free pinned shortcuts.
- Full-height native library editor, validation, atomic data persistence and remembered automatic mnemonic shortcuts.
- Exact Wayland clipboard text and immediate exit.
- Hyprland floating on first map without reflowing other tiled windows.
- Desktop light/dark appearance, CLI validation and diagnostic mode.

### Artifacts

- **trievium-linux-x86_64.tar.gz**: Linux x86_64 executable and MIT license.
- **SHA256SUMS**: archive integrity file; verify with `sha256sum -c SHA256SUMS`.

Runtime requirement: `wl-clipboard`. Archive is not a distro package or installer.

### Upgrade notes

The on-disk `items.json` schema remains `version: 1`, independent of app version. Existing entries need no migration. Pinned key assignments remain authoritative; cached automatic codes are best-effort stable as the library changes.

Subsequent work is bug fixes and maintenance, not feature expansion. See the [changelog](../../CHANGELOG.md), [acceptance record](../MVP_ACCEPTANCE.md), and [compatibility policy](../RELEASE.md).
